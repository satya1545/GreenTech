Green Tech – E-commerce Platform for Plants 🌱
Project Overview
Green Tech is an e-commerce website designed for plant enthusiasts to explore, select, and purchase a variety of plants and gardening supplies. The platform provides a seamless shopping experience with a user-friendly interface, product catalog, shopping cart, and secure payment integration.

Features
✅ User Authentication – Sign-up and login functionality for customers.
✅ Product Catalog – Browse plants with categories and filtering options.
✅ Shopping Cart & Checkout – Add items to cart, review purchases, and complete payments.
✅ Secure Payment Gateway – Ensures safe transactions for online purchases.
✅ Admin Dashboard – Manage products, orders, and inventory.
✅ Responsive UI – Mobile-friendly design for easy access on any device.

Tech Stack 🛠️
Frontend: HTML, CSS, JavaScript
Backend: Google Sheets (used as a database)
